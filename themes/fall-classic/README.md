# Fall Classic

[![Download all verified themes](https://img.shields.io/badge/nightly.link-download_themes-7c3aed?style=for-the-badge)](https://nightly.link/nuttyinc578/the-cube/workflows/themes/main/The-Cube-Beta-Themes.zip)

Version `1.0.0` by **nutty'inc**.

Warm maple leaves, harvest sunlight, and a deep autumn lake.

Drag `fall_classic.py` and `fall-classic.jar` onto the in-game Theme Store, verify them, then create a backup and install.

> [!WARNING]
> Themes can rewrite the whole game experience configuration. The Cube Beta creates a complete restore snapshot before installation. The Python manifest is not executed, and the JAR cannot contain executable code.
