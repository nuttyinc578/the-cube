# The Cube Beta Fall Edition 6.2.1

> [!CAUTION]
> **CRITICAL SUPPORT NOTICE:** The Cube Beta 5.0 is no longer supported. It will not receive bug fixes, compatibility updates, security updates, or technical support. Upgrade to 6.2.1.

The 6.2.1 release packages the Fall Edition as a custom Windows installer and a portable ZIP.

## Highlights

- Cube Physics Engine (CPE) and Integrated Particle Engine (IPE) physics rendering
- multiplayer host and guest support
- random interactive shapes and seasonal fall events
- Python and Ruby drag-and-drop add-ons
- Node.js, Java, Go cache, and .NET Aspire CPE bridges
- MIT License acceptance page in the custom installer
- Fall Edition music and summer-to-fall countdown updates

## Downloads

- `The-Cube-Beta-Fall-6.2.1-Setup.exe` — recommended Windows installer
- `The-Cube-Beta-Fall-6.2.1-Portable.zip` — portable game package
- `SHA256SUMS.txt` — SHA-256 checksums for both downloads

The Windows files are not digitally signed, so Microsoft Defender SmartScreen may show an unknown-publisher warning.
