# The Cube Beta 6.4.2 — stable Fluent Halloween

The tested Fluent Halloween update is now stable. This is a new 6.4.2 build, with stable version metadata and a separate installer; the old 6.4.2-nightly release remains available for reference.

- Fluent home, theme gallery, settings and loading screens; Halloween by default.
- Seven built-in themes and the original click sound.
- Official updater with SHA-256 verification and explicit installation consent.
- CPELoader integrity warnings and unlocked/custom-build update restrictions.
- Python 3.15.2, pygame-ce 2.5.8 and Pymunk 7.3.1.

Use the MIT-consent installer or extract the entire portable ZIP to a new empty folder. Do not overwrite your existing game, mods or backups. The installer is unsigned, so Windows may display an unknown-publisher warning.

The Power & Remastered release date is still to be announced. This release does not start public GameLift hosting. Christmas features and CPE 0.0.3-nightly are reserved for 6.4.3-nightly.
